risk_distributions has moved
============================

This documentation site is **archived**. The ``risk_distributions`` package has
been renamed and migrated into the
`vivarium-suite monorepo <https://github.com/ihmeuw/vivarium-suite>`_.

Which docs do you want?
-----------------------

If you have a specific version pinned (e.g. ``risk_distributions==2.3.4``):

  Stay on this site and use the **version selector** of the  page to switch to your
  installed version. Those releases still ship the original ``risk_distributions``
  module and the per-version API reference is preserved for them.

If you are not pinned or you are otherwise on ``risk_distributions >= 2.3.5``:

  You are running the **shim release**, which installs
  `vivarium-risk-distributions <https://pypi.org/project/vivarium-risk-distributions/>`_
  under the hood. The real code lives at the new import path ``vivarium.risk_distributions``.
  Go to https://vivarium-risk-distributions.readthedocs.io/ for current docs.
